# Contribuer à Kozé

Merci de vouloir aider ! Kozé est gratuit pour toujours, sans publicité, sans compte et sans collecte de données. Les contributions doivent respecter ces principes.

## Licence des contributions

En proposant une contribution (pull request, patch, etc.), vous acceptez qu'elle soit distribuée sous les mêmes conditions que le reste du projet :

- la [GNU GPL version 3](LICENSE),
- **avec** la permission additionnelle décrite dans [LICENSE-APP-STORE-EXCEPTION](LICENSE-APP-STORE-EXCEPTION), qui permet de publier l'application sur l'App Store et Google Play.

Chaque commit doit être signé avec `git commit -s` (Developer Certificate of Origin, https://developercertificate.org). Cette signature certifie que vous avez le droit de soumettre ce code sous ces conditions.

## Principes

- Accessibilité d'abord : grandes zones tactiles, contraste élevé, `accessibilityLabel` sur chaque élément interactif.
- Aucune dépendance incompatible avec la GPL-3.0.
- Aucun service tiers qui collecte des données.

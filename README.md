# Kozé

Application gratuite de communication alternative et augmentée (CAA) par pictogrammes, pour les personnes qui ne peuvent pas ou peu parler (autisme, aphasie, SLA, paralysie cérébrale…).

- Gratuite pour toujours, sans publicité, sans compte, sans collecte de données
- Fonctionne hors ligne une fois les pictogrammes affichés
- Synthèse vocale de l'appareil
- Mode aidant (appui long sur ⚙︎) pour ajouter ou supprimer des pictogrammes

## Développement

```bash
npm install
npx expo start
```
